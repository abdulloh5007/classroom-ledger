## Исходное ТЗ

CRUD учеников, добавление и история оплат, должники за месяц, любая БД и один интерфейс на выбор — бот **или** веб. Дополнительно — запуск в README, 3–5 идей развития и честный рассказ об ИИ.

В проекте появились оба интерфейса. Расчётами управляет один сервисный слой; бот не ходит в API по HTTP.

## Подготовлено в 2.0.0-beta.1

### Начало обучения

У группы появилась фактическая дата старта `startsOn`, у ученика — `enrolledOn`. Техническое время `createdAt` остаётся отдельным. Первым расчётным периодом становится более поздний из месяцев начала группы и зачисления.

До этого периода нет начисления; оплатить за более ранний месяц нельзя. В неполном первом месяце сохраняется полная месячная сумма. Сдвиг даты не может сделать уже зачтённую оплату недействительной.

При миграции старые даты остаются неподтверждёнными. Их нельзя случайно изменить на сегодняшние простым сохранением имени: в форме есть отдельное подтверждение фактической даты.

### Предоплата

Дата поступления денег и учебный месяц разделены. Например, деньги, полученные в октябре за ноябрь, остаются октябрьским поступлением, но уменьшают ноябрьский остаток.

Одно поступление можно распределить на несколько месяцев. Веб предлагает до 12, API — до 24 уникальных периодов; суммы должны точно совпадать. Проверка остатка и запись распределений выполняются одной транзакцией. В истории видны дата получения и зачтённые месяцы. Будущий hero показывает полученную предоплату, а не просрочку.

В боте период меняется кнопками, включая будущий месяц. Токен подтверждения меняется вместе с периодом, поэтому старая кнопка не создаёт неверную оплату. USD-оплаты в боте по-прежнему отключены.

### Учитель / Администратор / Владелец

| Возможность                                              | Учитель | Администратор | Владелец |
| -------------------------------------------------------- | :-----: | :-----------: | :------: |
| Управлять своими/назначенными группами и учениками       |    ✓    |       ✓       |    ✓     |
| Вносить оплату, смотреть историю и долги доступных групп |    ✓    |       ✓       |    ✓     |
| Видеть все группы центра                                 |    —    |       ✓       |    ✓     |
| Создавать курсы и менять их цены                         |    —    |       ✓       |    ✓     |
| Назначать роли и группы сотрудникам                      |    —    |       —       |    ✓     |
| Создавать логины и выдавать временные пароли             |    —    |       —       |    ✓     |
| Выдавать и отзывать Telegram-доступ по ID                |    —    |       —       |    ✓     |
| Смотреть журнал действий                                 |    —    |       —       |    ✓     |

Роли проверяются на сервере одинаково для веба, API и бота. Учитель автоматически получает созданную им группу. Подмена ID не открывает чужого ученика; старый формат создания ученика не позволяет обойти запрет на изменение курсов.

Владелец управляет сотрудниками в новом drawer. Временный пароль нужно сменить при первом веб-входе. Пароли хранятся как scrypt-хеши с солью; смена пароля, роли, назначений или активности отзывает сессии. Бот читает актуальные права при каждом действии, включая параллельные обновления разных пользователей.

### Безопасная подготовка

Ветка, каталог, база, порт и имя cookie отделены от 1.3.0. Preview не принимает токен рабочего бота и путь к рабочей БД. Миграция v8→v10 проверяется на синтетической старой схеме. Демо-скрипт создаёт вымышленные данные и отдельные аккаунты, а не копирует учеников рабочего центра.

## Что пока скрыто или ограничено

- Переключатель языка остаётся скрытым; новые административные экраны beta пока на русском.
- Отдельной вкладки курсов нет: курс создаётся из формы группы, каталог API сохранён.
- В v1.3 кнопка выхода скрыта; в v2 выход доступен в профиле для переключения персональных аккаунтов.
- Бот принимает только UZS. Preview проверяет его через mock transport и не запускает рабочий polling.
- Перевод ученика с оплатами в другую группу временно запрещён, чтобы не переписать прежние финансовые отчёты.

## Следующие этапы

1. **История обучения:** переводы между группами, паузы и завершение с отдельными периодами принадлежности.
2. **Финансовые операции:** отмена с причиной, возврат, перенос остатка и CSV по валютам.
3. **Большие списки:** серверная пагинация, поиск и фильтры справочников.
4. **Эксплуатация:** Docker/CI, регулярные резервные копии с проверкой восстановления, мониторинг, постоянный домен.
5. **Ручная проверка:** Safari/iPhone, реальные Telegram-клиенты и завершение новых переводов RU/UZ.

Код beta подготовлен для проверки отдельно от production. Установка на рабочий сайт — отдельное действие после решения о выпуске; сейчас оно не выполняется.
