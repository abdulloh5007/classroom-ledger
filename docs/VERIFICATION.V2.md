# Проверка 2.0.0-beta.1

21 октября 2026 года · Node.js 24.22.0 · ветка `next/v2`.

**Эта версия подготовлена отдельно. Production 1.3.0 не обновлялся.** Рабочая база не копировалась, не открывалась новой версией и не мигрировала; рабочий Telegram polling не перезапускался.

Новые проверки охватывают начало группы, зачисление, отсутствие долга до первого учебного месяца, предоплату независимо от даты получения, несколько периодов в одной транзакции, запрет переплаты и частичной записи, сохранение старых сумм, дат и ID при миграции настоящей схемы v8 на синтетических данных.

Проверены роли, назначенные группы, подмена ID, обход через старый контракт ученика, временный пароль, отзыв сессий и актуальность Telegram-доступа. При ревью нашли и закрыли возврат к общему сервису после отзыва сессии между хуками, а также повторный импорт отвязанного старого Telegram ID при следующем старте. Для обоих случаев есть регрессионные проверки. Прежние тесты SQL/HTML-инъекций, CSRF, лимитов, каскадного удаления и валют также прошли.

## Браузер

Chromium / Playwright запускался на случайных loopback-портах с вымышленными учениками и отдельными SQLite `:memory:`. Рабочий URL и реальные пароли в сценариях не использовались.

- Владелец создаёт учителя, задаёт временный пароль, Telegram ID и назначенную группу.
- При первом входе учитель меняет пароль; чужие ученики и управление сотрудниками недоступны, прямой запрос изменения цены возвращает 403.
- Получение денег сегодня за два следующих месяца сохраняет исходную дату и два распределения; долг текущего месяца не закрывается этой предоплатой.
- Старая группа переименовывается без вымышленного подтверждения даты. Новая группа с будущим началом не показывает преждевременный долг; календарь ограничивает зачисление и кнопку «Текущий».
- Меню владельца с 27 группами помещается в короткий экран 390×500.
- Нет горизонтального переполнения при ширине 360, 390, 720 и 1280 px; нет JavaScript pageerror.
- axe WCAG A/AA для формы сотрудников и оплаты, включая тёмную тему: нарушений нет **за исключением `meta-viewport`**. Запрет масштабирования сохранён по прежнему требованию пользователя; полное соответствие WCAG не заявляется.

Снимки содержат только вымышленные записи: [сотрудники](screenshots/v2/staff.png), [предоплата](screenshots/v2/prepayment.png), [кошелёк](screenshots/v2/wallet.png), [будущая группа](screenshots/v2/future-group.png). Браузерные QA-сценарии выполнялись внешним локальным стендом; в `npm test` входят сервисные, API- и bot-mock тесты.

## Локальный preview

Отдельный экземпляр работает на `127.0.0.1:3108` с собственной `data/preview.db`, вымышленными записями и пустым BOT_TOKEN. Проверены health, страница входа, about, вход владельца, профиль/роли, выход и 401 для гостя. Это локальный адрес, без внешнего tunnel.

## Что не проверено и не выпущено

Физический Safari/iPhone, отдельный настоящий тестовый Telegram-бот, восстановление резервной копии реальной базы и перенос production требуют отдельного прохода перед выпуском. Telegram проверен mock transport; это не подтверждает доставку настоящим клиентом. Полномасштабный DDoS/независимый пентест не проводился.

Docker/CI, CSV, возвраты и история переводов с оплатами не входят в эту beta. Правила защиты описаны в [SECURITY.V2.md](SECURITY.V2.md), будущая миграция и откат — в [V2_RELEASE.md](V2_RELEASE.md).
