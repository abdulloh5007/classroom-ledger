## Выпуск 1.3.0: одноразовый администратор по /start

Логин и пароль рабочего экземпляра изменены только в исключённом из Git файле .env. Конфигурация принимает пароль от шести символов и по-прежнему читает секреты исключительно из .env; фактический пароль не включён в исходники, справку или тесты. Новый вход, HttpOnly cookie, защищённый API и выход проверены через localhost. Старые сессии перестают подходить после смены реквизитов.

Владелец может включить или отменить одноразовую автовыдачу в /admins. Следующий новый человек с оригинальным /start в личном чате получает права администратора и соответствующее меню. Само приложение не включает этот режим при старте: новый экземпляр по умолчанию закрыт. Для рабочего экземпляра режим явно включён по просьбе владельца; проверка после выпуска показала, что приглашение ожидает пользователя. Тестовые /start в настоящий Telegram не отправлялись.

Миграция v7→v8 добавила только таблицу bot_admin_enrollment: контрольная сумма прежних таблиц до и после совпала, foreign_key_check пуст.
